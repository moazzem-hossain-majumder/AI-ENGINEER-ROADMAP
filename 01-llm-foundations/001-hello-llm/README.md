## 📖 Concept Explanation: What happens during an API call?

When you call an LLM API, you are **not** chatting with a sentient brain; you are making an HTTP POST request to a high-performance inference cluster.

```
┌─────────────────────────────────┐
│          Your Python App        │
└────────────────┬────────────────┘
                 │ 1. Sends JSON Payload:
                 │    {
                 │      "model": "openai/gpt-oss-20b",
                 │      "messages": [
                 │        {"role": "system", "content": "You are a concise tutor."},
                 │        {"role": "user", "content": "What is an embedding?"}
                 │      ]
                 │    }
                 ▼
┌─────────────────────────────────┐
│     Inference Engine (Groq)     │
│   Tokenizes prompt ➔ Predicts   │
│   next tokens until [STOP] token │
└────────────────┬────────────────┘
                 │ 2. Returns JSON Response:
                 │    {
                 │      "choices": [{"message": {"role": "assistant", "content": "..."}}],
                 │      "usage": {"prompt_tokens": 18, "completion_tokens": 42}
                 │    }
                 ▼
┌─────────────────────────────────┐
│          Your Python App        │
│   Extracts text & prints stats  │
└─────────────────────────────────┘
```

### 1. The Roles Explained
* **`system`**: The instructions, persona, and behavioral guardrails for the model. The model reads this before attending to the user.
* **`user`**: The prompt or query submitted by the human/client.
* **`assistant`**: The response generated by the model.

### 2. Token Usage Metadata
Every response includes a `usage` object:
* **`prompt_tokens`**: How many tokens your system + user message consumed.
* **`completion_tokens`**: How many tokens the model generated in response.
* **`total_tokens`**: The sum of both. This is what you pay for in production!

## 💻 Code Walkthrough (`main.py`)

Here is how the code is structured:

1. **Load Environment:** `dotenv.load_dotenv()` reads `GROQ_API_KEY` and `GEMINI_API_KEY` from the root `.env`.
2. **Initialize Client:** Create a client instance (`Groq()` or `genai.Client()`).
3. **Dispatch Request:**
   ```python
   response = client.chat.completions.create(
       model="openai/gpt-oss-20b",
       messages=[
           {"role": "system", "content": "You are a concise AI mentor."},
           {"role": "user", "content": "Explain what an AI Engineer does in 2 sentences."}
       ]
   )
   ```
4. **Extract Response & Metrics:**
   - Content: `response.choices[0].message.content`
   - Tokens: `response.usage.prompt_tokens` and `response.usage.completion_tokens`

## 🧪 Hands-On Exercises (Try These!)

1. **Change the system prompt:** Change `"You are a concise AI mentor"` to `"You are a pirate who explains tech concepts in pirate slang"`. Observe how the exact same user query produces a completely different tone.
2. **Inspect token count:** Ask a 1-word question (`"Hi"`) vs a 50-word question. Notice how `prompt_tokens` scales linearly with the input length.
3. **Switch models:** In `main.py`, try changing the model to `qwen/qwen3.8-27b` and notice the difference in speed and response style.
